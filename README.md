# kaigotool — 介護費用申請自動化

1 つの画面で、タブを切り替えて使います。

- **Step1 領収書取得**: Gmail から領収書を取得し `介護用品領収書\YYYYMM` に保存（ホームケア / まごころを選択可）
- **Step2 申請入力**: ベネフィット・ステーションの申請フォームへ入力（送信は手動）

Step2 は Step1 と独立して使えます。

## セットアップ（Windows、初回のみ）

1. **Python 3.11 以上**をインストール
2. VS Code のターミナルでライブラリをインストール（**起動に使う Python と同じもの**で）:
   ```
   & C:\Users\you50\.local\bin\python3.14.exe -m pip install -r C:\Users\you50\Downloads\kaigotool-claude-kaigo-insurance-automation-h38m9n\requirements.txt
   ```
   ブラウザはインストール済みの Edge を使うので `playwright install` は不要です。

## 起動

ツールを置いたフォルダのパスに合わせて実行します（パスに空白が含まれる場合は `"` で囲む）。

```
& C:\Users\you50\.local\bin\python3.14.exe C:\Users\you50\Downloads\kaigotool-claude-kaigo-insurance-automation-h38m9n\app.py
```

### 設定の保存

申請者情報・Gmail・領収書フォルダなどは画面で入力し、「**設定を保存（次回の既定値にする）**」を押すと
次回起動時からその値が初期表示されます。保存先は `%LOCALAPPDATA%\kaigotool\settings.json`（この PC の中だけ。
GitHub には上がりません）。以前の `config.toml` が同じフォルダにあれば、初回だけその値を取り込みます。

## Step2 申請入力

**入力方法**を選べます。

| 入力方法 | 内容 |
| --- | --- |
| PDF から読み取り、合計を自動計算 | 対象年月を選んで「PDF から読み込み」。フォルダの領収書から発行年月日・金額を読み取り、ご申請合計金額を自動計算します。読めなかった欄は手入力すると合計に反映されます |
| 画面に入力した内容をそのまま使う | PDF は使わず、画面の発行年月日・ご申請合計金額をそのままサイトに入力します |

- ①〜⑤の枠は「種類」でホームケア / まごころを選ぶとメニューNo.・メニュー名が入ります（直接編集も可）。
  発行年月日が空の枠は使いません。使う枠は詰めて ①②… に入力します。
- 「申請画面を開いて入力」で Edge が開きます。ログインが必要ならログインしてください（ログイン状態は保持されます）。
  「申し込む」→ フォーム入力まで自動で行い、**「次へ」以降はご自身で操作**します。入力できなかった項目はログに表示されます。
- 空欄の項目はサイトに入力しません。

PDF の命名規則（Step1 でも手動でも同じ）:

```
介護用品領収書\YYYYMM\領収書ホームケア_YYYYMM.pdf
介護用品領収書\YYYYMM\領収書まごころ_YYYYMM.pdf
（同じ月に複数あるときは _1, _2 … を付ける）
```

読み取り元: ホームケア = ご注文日 /「合計金額」行の小計、まごころ = 発行日 / 総合計。
Microsoft Print to PDF で保存した PDF は文字情報が無いことが多く読み取れません。
Edge の印刷で「**PDF として保存**」を選ぶと読み取れます。

## Step1 領収書取得

対象年月（当月が初期値。一覧にない年月も直接入力可）と対象サイトを選んで「領収書を取得」。
Gmail の**アプリ パスワード**が必要です:

- Google アカウント → セキュリティ → 2 段階認証プロセスを有効化
- https://myaccount.google.com/apppasswords で作成し、画面の「アプリ パスワード」欄に入力
- Gmail の設定 →「メール転送と POP/IMAP」→ IMAP を有効化

取得が終わると Step2 の対象年月に引き継がれ、PDF を自動で読み込みます。
