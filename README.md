# kaigotool — 介護費用申請自動化

1 つの画面で、タブを切り替えて使います。

- **Step1 領収書取得**: Gmail から領収書を取得し `介護用品領収書\YYYYMM` に保存（ホームケア / まごころを選択可）
- **Step2 申請入力**: ベネフィット・ステーションの申請フォームへ入力（送信は手動）

Step2 は Step1 と独立して使えます。

## 起動（Windows）

フォルダ内の **`start.bat` をダブルクリック**してください。

- 初回だけ、このフォルダに専用の Python 環境（`.venv`）を作ってライブラリを入れます（数分）。
  uv で入れた Python は直接ライブラリを入れられない（externally-managed-environment エラー）ため、この方式にしています。
- 2 回目以降はすぐ画面が開きます。
- ブラウザはインストール済みの Edge を使うので `playwright install` は不要です。

VS Code のターミナルから手動で行う場合:

```
cd C:\Users\you50\Downloads\kaigotool-claude-kaigo-insurance-automation-h38m9n
& C:\Users\you50\.local\bin\python3.14.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

### 設定の保存

申請者情報・Gmail・領収書フォルダなどは画面で入力し、「**設定を保存（次回の既定値にする）**」を押すと
次回起動時からその値が初期表示されます。保存先は `%LOCALAPPDATA%\kaigotool\settings.json`（この PC の中だけ。
GitHub には上がりません）。以前の `config.toml` が同じフォルダにあれば、初回だけその値を取り込みます。

## Step2 申請入力

**入力方法**を選べます。

| 入力方法 | 内容 |
| --- | --- |
| PDF から読み取り、合計を自動計算 | 対象年月を選んで「PDF から読み込み」。フォルダの領収書から発行年月日・金額を読み取り、ご申請合計金額を自動計算します。読めなかった欄は手入力すると合計に反映されます |
| 画面に入力した内容をそのまま使う | PDF は使わず、画面の発行年月日・ご申請合計金額をそのままサイトに入力します |

- ①〜⑤の枠は「種類」でホームケア / まごころを選ぶとメニューNo.・メニュー名が入ります（直接編集も可）。
  発行年月日が空の枠は使いません。使う枠は詰めて ①②… に入力します。
- 申請サイトへの入力は 2 段階です（Cloudflare の認証を通すため、ログインはご自身で行います）:
  1. 「**① 申請用 Edge を開く**」→ 開いた Edge でログインし、申込プラン（または申込入力）画面を開く
  2. 「**② 開いている申請画面に入力**」→ その Edge に接続し、「申し込む」→ フォーム入力まで行う
  - 申請用 Edge は普段の Edge とは別のウィンドウ（別プロファイル）で、ログイン状態はそこに残ります
  - **「次へ」以降はご自身で操作**します。入力できなかった項目はログに表示されます
- 空欄の項目はサイトに入力しません。
- 「ご利用規約は、ご確認されましたか」「不備の場合は…」「ご入力の最終画面にて…」は自動で「はい」にチェックします
  （規約の確認と最終確認は、ご自身が規約を見て起動し「次へ」を押すことをもって行う運用）。
- **ファイル添付**（画面の「ファイル添付」でオン/オフ可）:
  - ①領収書・明細書 … 対象年月フォルダの PDF をすべて添付（領収書ホームケア → まごころ → その他の順）
  - 介護保険証（介護保険被保険者証）の写し … 指定フォルダ（初期値 `介護用品領収書\毎回添付物`）の PDF を添付。
    フォルダは画面で変更でき、「設定を保存」で次回の既定値になります
  - サイトの制限（1 ファイル 5MB まで・1 項目 5 ファイルまで）を超える分は添付せず、ログに表示します

PDF の命名規則（Step1 でも手動でも同じ）:

```
介護用品領収書\YYYYMM\領収書ホームケア_YYYYMM.pdf
介護用品領収書\YYYYMM\領収書まごころ_YYYYMM.pdf
（同じ月に複数あるときは _1, _2 … を付ける）
```

読み取り元: ホームケア = ご注文日 /「合計金額」行の小計、まごころ = 発行日 / 総合計。
Microsoft Print to PDF で保存した PDF は文字情報が無いことが多く読み取れません。
Edge の印刷で「**PDF として保存**」を選ぶと読み取れます。

## Step1 領収書取得

対象年月（当月が初期値。一覧にない年月も直接入力可）と対象サイトを選んで「領収書を取得」。

1. `YYYYMM` フォルダが既にあればそれを使い、無ければ作成します
2. **ホームケア**: フォルダに `領収書ホームケア_YYYYMM.pdf` があれば終了。無ければメールの電子領収書 URL を PDF 保存
3. **まごころ**: フォルダに `領収書まごころ_YYYYMM.pdf` があれば終了。無ければ
   - フォルダ内に**命名規則に当てはまらない PDF**（手動でダウンロードしたもの等）があれば、
     それを `領収書まごころ_YYYYMM.pdf` にリネームして終了（複数あれば古い順に `_1`, `_2` …）
   - 無ければメールの注文番号で納品書ページ（ラク帳票）を開き、注文番号・**電話番号**を入力 →「ログイン」→
     「領収書・納品書を発行する」でダウンロード（ポップアップで届くファイルも受け取ります）して保存
4. 「既存の領収書ファイルがあってもメールから取り直す」にチェックすると、既存ファイルやリネームを使わずメールから取得します

メールから取得する場合だけ、Gmail の**アプリ パスワード**と電話番号（まごころ）が必要です:

- Google アカウント → セキュリティ → 2 段階認証プロセスを有効化
- https://myaccount.google.com/apppasswords で作成し、画面の「アプリ パスワード」欄に入力
- Gmail の設定 →「メール転送と POP/IMAP」→ IMAP を有効化

取得が終わると Step2 の対象年月に引き継がれ、PDF を自動で読み込みます。
